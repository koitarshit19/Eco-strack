# 🌍 EcoTrack

EcoTrack is a modern, responsive web application designed to simplify sustainability. The platform empowers individuals to calculate, monitor, and intelligently reduce their daily carbon footprint by translating complex environmental data into clear, actionable, and visual insights.

🚀 **Live Demo:** [https://ecotrackking.netlify.app/](https://ecotrackking.netlify.app/)

---

## ⚡ Key Features

* **Real-Time Calculation:** Seamlessly processes user inputs (commuting, lifestyle, energy usage) to instantly calculate carbon footprint scores.
* **Responsive & Minimalist UI:** Optimized for a smooth user experience across desktops, tablets, and smartphones.
* **Component-Driven Metrics:** Uses dynamic state management to ensure calculations update instantaneously without requiring page reloads.
